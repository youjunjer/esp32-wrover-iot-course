# 接線與操作安全

## 低電壓實驗

- LED 串聯適當的限流電阻，不將 LED 直接跨接電源。
- 改動接線前先斷開 USB 與外部電源。
- 接上訊號線前先確認 VCC、GND 與腳位電壓。
- 外部供電裝置與 ESP32 必須共地，但不將不同電壓電源直接並聯。
- SG90 不建議由 ESP32 3.3V 腳供電；使用適當的 5V 電源並共地。

## 繼電器

- 先不接市電負載，只使用低電壓 LED 測試負載與 OLED 狀態畫面確認控制邏輯。
- 確認模組為高電位或低電位觸發。
- 程式啟動時先設定為安全的關閉狀態，不讓開發板重啟造成負載意外通電。

## PZEM-004T 與市電

- PZEM-004T 市電側可能涉及致命電壓。
- 課堂與遠端問答不引導學生帶電接線。
- 市電端必須斷電、絕緣、加裝保護外殼，並由具備合適資格的人員處理。
- 程式與 UART 測試優先使用已完成安全封裝的教學設備。
