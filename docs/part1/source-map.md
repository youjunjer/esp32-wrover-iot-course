# 第一篇來源與遷移記錄

第一篇以 AB143 的教學順序與實驗腳位為基礎，但不直接複製舊版課本。歷史範例會先與 NMK99 及能源監測專案交叉比對，再依 ESP32 Core 3.3.11、可見化診斷與電氣安全原則重寫。

## 範例對應

| 新範例 | AB143 來源 | 保留內容 | 現代化處理 |
|---|---|---|---|
| `01_hello` | P23 HelloWorld | 第一支程式與重複執行概念 | 將 Serial-only 輸出改為 GPIO 2 啟動碼與心跳 |
| `02_led` | P30 LED 閃爍 | GPIO 2、亮暗各 1 秒 | 使用常數腳位與安全的預設熄燈 |
| `03_button_led` | 新增 | 數位輸入與輸出 | 外接 GPIO 13 按鈕，避免把 BOOT 鍵當作初學按鈕 |
| `04_button_toggle` | 新增 | 判斷、布林狀態與 `millis()` | 加入 30 ms 非阻塞防彈跳 |
| `05_traffic_light` | P33 LED 紅綠燈 | 紅 4／黃 2／綠 15，紅 3／黃 1／綠 5 秒 | 上電先全關，再以紅燈作為安全起點 |
| `06_pwm_fade` | P48 LED PWM | GPIO 15、0→255→0、每步 10 ms | 將舊寫法改為 Core 3.x `ledcAttach()` 與 `ledcWrite()` |
| `07_rgb_led` | P56 MQ-2 與 RGB LED | RGB 程式腳位 R15／G2／B4 | MQ-2 移到 OLED 後；RGB 改為三路 LEDC PWM |
| `08_ws2812` | P249 Neo 閃光燈 | GPIO 32、1 顆、白→紅→綠→藍→關 | 限制全域亮度並鎖定函式庫版本 |

NMK99 與 `esp32-mqtt-energy-meter` 的 GPIO 2 LED、GPIO 32 WS2812 及紅 4／黃 2／綠 15 燈號也用來交叉確認一般模式腳位。

## 已解決的舊版矛盾

- AB143 四版的 RGB 接線文字與程式不一致。本教材以三版及四版程式一致的 R15／G2／B4 為準。
- 舊版 PWM 文字曾出現 GPIO 2，但程式使用 GPIO 15。本教材統一使用 GPIO 15。
- 舊版範例的 `analogWrite()` 雖仍可用，但不利於明確的 LEDC 初始化與錯誤處理，因此改用 Core 3.x LEDC API。
- Core 3.x 已移除舊版 LEDC 設定函式，正式 Sketch 中不得使用。

## 移到第二篇的內容

光敏電阻、MQ-2 與其他需要觀察數值的感測器不放在第一篇。第二篇先建立 OLED 啟動自測與錯誤顯示，之後才能對感測數值、無資料、逾時及不合理值進行可見化驗證。
