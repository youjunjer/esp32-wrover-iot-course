# 第二篇：OLED、感測器與顯示器

Codex 輔助實機開發時不一定能直接取得序列監控畫面，因此本篇先完成 OLED，讓後續感測器都有可拍照、可辨識的狀態輸出。

規劃順序：

1. OLED 啟動自測與 I²C 自動尋址
2. OLED 基礎顯示
3. OLED 可視化診斷畫面
4. 感測器接線與供電
5. PIR 人體感測器
6. 光敏電阻與類比輸入
7. MQ-2 氣體感測器
8. 超音波測距
9. 蜂鳴器與倒車雷達
10. DHT11 溫濕度
11. 1602 LCD 與 DHT11 整合
12. DHT11＋光敏電阻＋OLED 多頁顯示

從 OLED 章開始，每一個 ESP32 執行階段訊息都必須先呈現在 OLED，包括無感測資料、連線失敗、重試、資料逾時與錯誤碼；Serial 只能同步複製。範例將在確認腳位、函式庫與 Core 3.x 編譯結果後逐一加入。
