# 03 按鈕控制 LED

這個範例練習數位輸入與數位輸出。按住按鈕時 LED 亮起，放開後 LED 熄滅；所有狀態都可直接從 LED 觀察，不需要序列監控器。

## 一般模式接線

| 元件 | ESP32 腳位 | 接法 |
|---|---:|---|
| LED | GPIO 2 | 若無可用的板載 LED，GPIO 2 經 220–330 Ω 限流電阻接 LED 正極，LED 負極接 GND |
| 外接按鈕 | GPIO 13 | 按鈕一端接 GPIO 13，另一端接 GND |

本教材統一使用 GPIO 13 外接按鈕與 `INPUT_PULLUP`，不使用 GPIO 0／BOOT 鍵作為初學按鈕。不要將 GPIO 13 直接 3.3V；內建上拉已讓放開狀態維持為 `HIGH`，按下接地時讀到 `LOW`。

## 可見驗證

1. 上電或重啟後，LED 預設熄滅。
2. 按住外接按鈕，LED 亮起。
3. 放開按鈕，LED 熄滅。

改動接線前先拔除 USB 與其他電源。LED 必須使用限流電阻；本範例假設 GPIO 2 的 LED 為高電位亮燈。

## 常見錯誤

- 按鈕無反應：確認使用按鈕真正會導通的兩腳，並確認一端是 GPIO 13、另一端是 GND。
- 程式邏輯相反：`INPUT_PULLUP` 的按下值是 `LOW`，不是 `HIGH`。
- LED 不亮：檢查 GPIO 2、LED 極性、限流電阻與共地。
