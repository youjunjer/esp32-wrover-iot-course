# 01 第一支可見程式

這個範例驗證開發板、編譯、燒錄、重啟、`setup()` 與 `loop()`。不使用序列監控器；GPIO 2 LED 就是執行狀態。

## 接線

若指定課程板沒有 GPIO 2 板載 LED，請外接：

```text
GPIO 2 ── LED 正極
LED 負極 ── GND
```

更換接線前先斷開 USB 與其他電源。

## 可見驗證

1. 上電或重啟後快閃三次，表示 `setup()` 已完成。
2. 接著每兩秒出現一次短心跳，表示 `loop()` 持續執行。

沒有亮燈時，先檢查是否使用可傳輸資料的 USB 線、是否燒錄到正確連接埠，再檢查 LED 腳位、極性與共地。

## 編譯目標

```text
FQBN: esp32:esp32:esp32wrover
ESP32 Core: 3.3.11
外部函式庫: 無
```
